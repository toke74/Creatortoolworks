# Content Publishing Workflow

## Goal
Use AI to accelerate research and drafting without publishing unverified, repetitive, or search-first filler.

## Workflow
1. Define the user question the content must answer.
2. Gather primary/authoritative sources for changeable facts.
3. Outline only the sections needed.
4. AI may draft from the approved outline/sources.
5. Fact-check every numeric/platform claim.
6. Remove generic filler and repeated sitewide language.
7. Add original example/methodology where helpful.
8. Confirm internal links serve the reader.
9. Review title/meta for accuracy, not clickbait.
10. Publish and monitor queries/engagement.
11. Refresh when source facts change.

## Content types
- Tool-page guidance.
- Methodology/limitations.
- Examples.
- Category introductions.
- Deep guides supporting creator workflows.
- Changelog/update notes for platform changes.

## AI writing rules
- Never invent survey data, RPM benchmarks, algorithm “secrets,” or YouTube ranking factors.
- Never claim a score predicts views/rank unless there is valid evidence.
- Never paraphrase one source into dozens of near-identical pages.
- Prefer direct practical guidance over long introductions.
- Cite official platform sources for volatile requirements.
