# Tool Taxonomy and Roadmap

## Taxonomy principles
- Categories describe creator workflows, not SEO keyword buckets.
- A tool belongs to one primary category and may have secondary tags.
- Similar ideas are merged before development.
- Category pages are useful browsing pages, not automatically generated thin landing pages.

## Proposed top-level categories

2. Thumbnails & Images
3. Descriptions & Metadata
4. Chapters & Timestamps
5. Keywords & Discovery
6. Shorts Tools

8. Planning & Ideation
9. Monetization & Revenue
10. Analytics & Math
11. Text & Formatting
12. Publishing QA
13. Accessibility & Captions
14. Workflow & Productivity

## Roadmap model

### Wave 1 — 6 tools
The approved MVP set.

### Wave 2 — up to 20
Adjacent tools with obvious reuse and distinct intent.

### Wave 3 — up to 50
Expand categories that show traffic and repeat usage.

### Wave 4 — 100+
Use reusable engines (text analysis, time parsing, image inspection, calculators) to create genuinely distinct tools.

### Wave 5 — 200–300+
Expansion is evidence-driven. Before approval, every tool must pass the Intent Differentiation Test below.

## Intent Differentiation Test
Before creating a page, answer yes to all:
1. Does this solve a task that a user can describe independently of an existing tool?
2. Does it require meaningfully different inputs, outputs, validation, or workflow?
3. Would merging it into an existing tool make that tool materially worse or confusing?
4. Can we explain its value without changing only a keyword or platform label?
5. Can we maintain its platform facts and tests?

If not, merge the idea into an existing tool or reject it.
