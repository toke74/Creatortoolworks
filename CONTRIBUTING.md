# Contributing

## Feature work
Every new tool requires an approved spec based on `docs/tools/TOOL-SPEC-TEMPLATE.md`.

## Pull requests
Keep one coherent feature/fix per PR. Include tests and note any platform facts/sources changed.

## Do not merge when
- required checks fail;
- output correctness is uncertain;
- source facts are stale/unsupported;
- the page is a near-duplicate of an existing tool;
- privacy/ad-policy concerns remain unresolved.
